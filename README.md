# 🌤 WeatherNow

A modern weather app built with HTML, CSS & JavaScript.

**Live Demo:** [your-aws-link-here]

## Features
- Real-time weather by city
- Dynamic backgrounds per weather condition
- °C / °F toggle
- Humidity, wind, sunrise/sunset
- Fully responsive

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- OpenWeatherMap API

## Setup
1. Clone the repo
2. Add your API key in `script.js`
3. Open `index.html` with Live Server
